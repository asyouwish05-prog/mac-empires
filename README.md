# McDonald's EMPIRES

マクドナルドの来店を戦国の陣取りに変える個人用アプリ。

- 公開URL: https://asyouwish05-prog.github.io/mac-empires/
- GoogleマップのAPIキーは「略 → 記録管理 → 地図」で端末ごとに保存（リポジトリには含めない）
- 必要なAPI: Maps JavaScript API / Places API (New)。キーはHTTPリファラー `https://asyouwish05-prog.github.io/*` に制限する
- 旧版（12号機）は `legacy-12.html`。旧版の戦歴（mac_v12）は新版の初回起動時に自動で引き継ぐ
